How a trade gets placed

1 · Candidate builder — plain code
Enumerates every credit spread and iron condor that is really in the chain, really quoted and really tradeable. The model is never asked to name a contract, so it cannot invent one.
priced at short-bid minus long-ask, never mid-to-mid
2 · Proposer — Claude Opus 5
Picks one key off that menu, or stands aside. Standing aside is a first-class answer.
can suggest · cannot place
3 · Risk Officer — independent model
Different model family, and never shown the Proposer's reasoning. Prompted to refute rather than assess, and to refuse when uncertain. Any failure to reach it counts as a veto.
can veto · cannot place
4 · Hard Gate — no model at all
Computes the worst case from the option legs itself rather than trusting the figure attached to the proposal. Unbounded risk is rejected outright, never sized down.
1.5% per trade · 6% portfolio · −3% daily stop · the only layer that can approve
